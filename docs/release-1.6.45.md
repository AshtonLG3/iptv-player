# Rugare TV 1.6.45

Android version code 72.

- The Wildlife category no longer matches any channel containing "wild". The Wild Wild West, Wild 'N Out and Wild at Heart now appear under General; WildEarth, Wild Nature, Wild TV and Terra Mater WILD remain in Wildlife.
- Removed Nature Time (not in English) and Yadah TV (its only listed feed carries RTM programming).
- Hid Nat Geo (India), Nat Geo Wild (India), Colors Infinity HD, Nick HD+ and Romedy Now while their shared source server refuses connections. They are not user-disabled, so the next refresh restores them when the feed responds.

Dark/light themes and the menu version are retained.

Verification: 120 automated tests pass and generated playlists match the registry. Signed code 72 installed over 1.6.44 on the Smart TV Pro and resumed SABC 1 at 1920x1080 about 2.5 seconds after launch.
