# Rugare TV 1.6.46

Android version code 73.

- Removed the empty program-guide row and the space it occupied between playback and Browse.
- A guide appears only when the selected channel has matching current or upcoming programmes, as a translucent overlay inside the video frame. Switching to a channel without data, removing a guide, or schedule expiry hides and collapses it.
- Optional XMLTV sources and file import remain in Settings. Starter guides cover particular Pluto TV/Plex regions and do not provide universal channel coverage.
- Dark/light themes and the version in the menu remain available.

Optional sources successfully downloaded during this release:

- Pluto TV US: https://raw.githubusercontent.com/matthuisman/i.mjh.nz/refs/heads/master/PlutoTV/us.xml.gz
- Plex UK: https://raw.githubusercontent.com/matthuisman/i.mjh.nz/refs/heads/master/Plex/gb.xml.gz

These are provider-specific guides; no Top Barça schedule was established.
